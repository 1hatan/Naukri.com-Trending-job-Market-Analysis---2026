# Excel Data Analytics Mini Project

This project demonstrates an end-to-end data analytics workflow using Microsoft Excel 365. It focuses on transforming raw data into meaningful business insights through professional data cleaning, preprocessing, data transformation, Pivot Table analysis, and interactive dashboard development.

### Key Highlights
- Raw Data Collection and Exploration
- Data Cleaning and Preprocessing
- Handling Missing and Duplicate Values
- Data Transformation using Power Query
- Pivot Table and Pivot Chart Analysis
- KPI Development
- Interactive Dashboard Creation
- Business Insights and Data Visualization

### Tools & Technologies
- Microsoft Excel 365
- Power Query
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Visualization

### Project Objective
To analyze raw datasets, identify meaningful patterns and trends, and present actionable insights through an interactive Excel dashboard.

### Project Outcome
Developed an interactive dashboard that converts raw data into structured information, helping users understand key metrics, trends, and business performance.
